# Data placement

The raw NTSB workbooks are not redistributed in this repository.

Place the following files in `data/raw/` or pass another directory with `--data-dir`:

- `events.xlsx`
- `aircraft.xlsx`
- `Flight_Crew.xlsx`
- `Findings.xlsx`
- `aviation_model_results_final.xlsx`
- `eADMSPUB_DataDictionary.xlsx`

Raw and derived record-level data should not be committed to GitHub. The source data are publicly available from the NTSB Aviation Accident Database.
