# Package contents

This public-release package is intentionally minimal.

Included:
- analysis source code
- executable scripts
- final configuration files
- automated tests
- final manuscript results
- final manuscript figures
- essential feature and split audits
- citation, license, and code-availability files

Excluded:
- raw NTSB data
- record-level analytical datasets
- duplicate `outputs/` and `results/` trees
- obsolete manuscript notes
- old workbook comparisons
- debugging and development-only audits
- duplicate or unused figures
